# Why Are Customers Leaving? — Telco Customer Churn Analysis

A Python data analysis project that finds out which telecom customers leave, why they leave, and what the business can do about it.

**Status:** 🚧 In progress

## Dataset
[IBM Telco Customer Churn](https://github.com/IBM/telco-customer-churn-on-icp4d) — 7,043 customers, 21 columns (contract, tenure, services, charges, churn).

## Tools
Python · pandas · NumPy · matplotlib · seaborn · scikit-learn · Jupyter
